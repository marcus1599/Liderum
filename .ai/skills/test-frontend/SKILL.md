# Test Frontend
**Consumidores:** Frontend Dev, QA. Leia plano/PRD, diff, `frontend/package.json`, componentes e specs.
## Procedimento
Use scripts existentes para teste/build/TypeScript; valide fluxo, erro, carregamento e acessibilidade básica quando UI mudar; investigue flakiness por repetição e prefira asserts comportamentais.
## Bloqueadores
Não introduza Playwright/dependência sem autorização. Teste, TypeScript, build falho ou flakiness não explicada bloqueia.
## Saída
Comandos, cenários, resultados e riscos.
